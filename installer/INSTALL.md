# Установка на новую ноду

## Двумя командами

```sh
curl -fsSL -o /tmp/rw-edge-install.sh \
  https://raw.githubusercontent.com/Vlone111/NodaFullScript/main/installer/rw-edge-install.sh
bash /tmp/rw-edge-install.sh
```

Скачать, потом выполнить. `curl | bash` не годится вовсе: скрипт задаёт
вопросы, а в конвейере stdin занят самим скриптом. Подстановка процесса
`bash <(curl ...)` эту проблему решает, но заводит свою — bash читает файл из
FIFO по мере выполнения, и при обрыве чтения curl падает с `(23) Failure
writing output to destination`, оставляя bash с обрывком скрипта.

Проверить, что скачалось целиком:

```sh
bash -n /tmp/rw-edge-install.sh   # молчит — синтаксис цел
```

Скрипт кладёт свою копию в `/opt/rw-edge/rw-edge-install.sh`, поэтому после
установки остаются доступны `verify`, `steps` и `rollback`:

```sh
/opt/rw-edge/rw-edge-install.sh steps
```

## Или клонированием

```sh
git clone https://github.com/Vlone111/NodaFullScript
cd NodaFullScript/installer
./rw-edge-install.sh
```

## Что подготовить заранее

1. **Чистый Debian или Ubuntu.** Скрипт ставит Docker сам, если его нет.
2. **Node в панели создан**, `SECRET_KEY` скопирован. Ввод скрытый.
3. **A-записи доменов** уже указывают на IP этой ноды. Сколько доменов нужно —
   зависит от выбранных транспортов, скрипт скажет и проверит через два
   независимых резолвера. AAAA не создавайте.
4. **Репозиторий с сайтом прикрытия** запушен и на нём стоит тег.
5. **Если нужны метрики** — URL `remoteWrite` вашего приёмника и basic-auth к
   нему. Пункт необязательный, от панели не зависит.

## Порядок вопросов

```
IP панели → порт Node API → SECRET_KEY
  → номера транспортов через пробел
  → домен под каждый выбранный транспорт
  → git-репозиторий сайта и тег
  → метрики: включать ли, URL приёмника, логин и пароль
```

Дальше без участия: sysctl, Docker, образы по digest, UFW, генерация ключей и
конфигов, клон сайта, разовое кодирование медиа, ACME, деплой, проверки и
печать инструкции для панели.

## После установки

Инструкция, что вставлять в Remnawave, лежит в
`/opt/rw-edge/private/PANEL-STEPS.txt` и печатается в конце установки.

Порядок в панели: Config Profile → Node → Hosts → Xray JSON Template →
Virtual Host → Subscription Settings.

Пока Config Profile не вставлен, backend-порты Xray не слушают — это нормально,
скрипт про это предупреждает отдельной строкой, а не молча.

Отдельно проверьте строку про сертификаты. Скрипт лезет за сертификатом каждого
домена и ругается, если тот выдан staging-центром: с таким сертификатом REALITY
продолжает работать (он его не использует), а TLS, XHTTP, gRPC и Hysteria2
клиенты отвергают по недоверию. Установка при этом выглядит полностью успешной,
поэтому проверка вынесена в явное предупреждение.

## Откат

```sh
/opt/rw-edge/rw-edge-install.sh rollback
```

Останавливает контейнеры (включая агент метрик) и снимает оба cron-хука —
синхронизацию сертификатов и сбор состояния контейнеров. Файлы, тома с сертификатами,
правила UFW и sysctl намеренно не трогает: их удаление — отдельное решение, а
не побочный эффект отката. Команды для полной очистки печатаются.
