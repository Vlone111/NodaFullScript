# Установка на новую ноду

## Одной командой

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/Vlone111/rw-edge/main/rw-edge-install.sh)
```

Работает именно так, а не через `curl | bash`: скрипт задаёт вопросы, а в
пайпе stdin занят самим скриптом и ответы читать неоткуда. Здесь используется
process substitution, а весь интерактив читается напрямую из `/dev/tty`.

Скрипт кладёт свою копию в `/opt/rw-edge/rw-edge-install.sh`, поэтому после
установки остаются доступны `verify`, `steps` и `rollback`:

```sh
/opt/rw-edge/rw-edge-install.sh steps
```

## Или клонированием

```sh
git clone https://github.com/__YOUR_GITHUB__/rw-edge
cd rw-edge
./rw-edge-install.sh
```

## Что подготовить заранее

1. **Чистый Debian или Ubuntu.** Скрипт ставит Docker сам, если его нет.
2. **Node в панели создан**, `SECRET_KEY` скопирован. Ввод скрытый.
3. **A-записи доменов** уже указывают на IP этой ноды. Сколько доменов нужно —
   зависит от выбранных транспортов, скрипт скажет и проверит через два
   независимых резолвера. AAAA не создавайте.
4. **Репозиторий с сайтом прикрытия** запушен и на нём стоит тег.

## Порядок вопросов

```
IP панели → порт Node API → SECRET_KEY
  → номера транспортов через пробел
  → домен под каждый выбранный транспорт
  → git-репозиторий сайта и тег
```

Дальше без участия: sysctl, Docker, образы по digest, UFW, генерация ключей и
конфигов, клон сайта, разовое кодирование медиа, ACME, деплой, проверки и
печать инструкции для панели.

## После установки

Инструкция, что вставлять в Remnawave, лежит в
`/opt/rw-edge/private/PANEL-STEPS.txt` и печатается в конце установки.

Порядок в панели: Config Profile → Node → Hosts → Xray JSON Template →
Virtual Host → Subscription Settings.

Пока Config Profile не вставлен, backend-порты Xray не слушают — это нормально,
скрипт про это предупреждает отдельной строкой, а не молча.

## Откат

```sh
/opt/rw-edge/rw-edge-install.sh rollback
```

Останавливает контейнеры и снимает cron-хук. Файлы, тома с сертификатами,
правила UFW и sysctl намеренно не трогает: их удаление — отдельное решение, а
не побочный эффект отката. Команды для полной очистки печатаются.
